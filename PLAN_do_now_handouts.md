# Plan — Standalone Do Now Handout PDFs

## Why

Teachers need a printable Do Now slip to hand to students at the door. Currently the Do Now lives inside the teacher packet (prose + teacher notes around it), not as a standalone handout. The only existing standalone `*_do_now.tex` is `L35_P4_do_now.tex` for assessment day. Every regular lesson needs one.

## Target: one PDF per lesson-period that has a Do Now

After this task, `ls tex/*_do_now.tex` should include roughly 18 files (one per lesson with a phases mapping). `ls tex/*_do_now.pdf` should match. Supabase Storage `lesson-pdfs` bucket should have `{lesson_id}_do_now.pdf` for each. Web UI gets a new "Do Now" button alongside Student/Teacher/Slides.

## Design constraints

- **Use existing `tex/preamble.sty`** — don't write a new stylesheet. Reuse `\packetheading`, `\bankitem`, `\callout`, section banners. Study `tex/L35_P4_do_now.tex` (already in the repo) as the style reference — it's hand-authored and matches the look the teacher prints today.
- **One standalone tex per lesson-period**, named `tex/{lesson_id}_do_now.tex` (e.g. `tex/L35_P2_do_now.tex`). `\documentclass[11pt]{article}` + `\usepackage{preamble}` + `\begin{document}` body + `\end{document}`.
- **Layout**: lesson header with `\packetheading{...}`, then a **Name / Period / Date** line, then the Do Now item(s) as `\bankitem` blocks with generous `\vspace{...}` for work area. Target: one lesson fits on ONE letter page (not 3-per-page; too cramped given some Do Nows are multi-part).
- **Multiple Do Nows per lesson**: lessons L63_P1, L64_P1, L65_P1 have 3 separate Do Now items (multi-phase Do Now pattern). All three must fit on the handout, in phase-position order. Adjust `\vspace` to keep it on one page (or let it flow to two — acceptable).
- **No visuals** for now — confirmed none of the Do Now items have `has_visual=true`. If a future Do Now needs a visual, we'll extend.
- **Prose-only Do Nows** (item_id=NULL in lesson_phases, e.g. "Do Now — Generalize: k in terms of x and y"): emit a `\bankitem{<label>}{<empty body, leave workspace>}` block. The teacher will write on the board anyway, but the handout still exists so students have a labeled slip.

## Files to create

### 1. `build_do_now_tex.py` (repo root)

Batch generator. Usage:
```
python build_do_now_tex.py                 # emit all
python build_do_now_tex.py L35_P2 L41_P1   # emit subset
python build_do_now_tex.py --pdf           # also run pdflatex
```

Logic:

1. **Discover lessons**: glob `tex/L*_teacher.tex` + `tex/APStats_*_teacher.tex` (skip `*_regen`).
2. **Extract Do Now items**: for each teacher tex, parse `\bankitem{Do Now <...>}{BODY}` patterns in order. You have two working references for the parser — pick whichever is cleaner:
   - `supabase/seed_lesson_phases.py` has a full phase-aware parser (`find_brace_group`, phase detection, label resolution).
   - `backfill_from_teacher_tex.py` has the same brace-balanced extractor.
   Copy/reuse; don't reinvent.
3. **Resolve body**: if LABEL has a parenthesized bank id (most cases), look up `prompt` in `questionbank/registry.jsonl` and use that as the body source of truth. If no bank id (prose-only Do Now), use the LABEL as the item's own display title and leave body empty with generous vspace.
4. **Emit tex** using this template (match `L35_P4_do_now.tex` style):

```tex
\documentclass[11pt]{article}
\usepackage{preamble}

\begin{document}

\packetheading{Lesson {X-Y} \textperiodcentered\ Period {N} \textperiodcentered\ Do Now}{{date-subtitle or topic short}}

\vspace{0.25em}
\noindent\textbf{Name:}\ \rule{2in}{0.4pt}\quad
\textbf{Period:}\ \rule{0.5in}{0.4pt}\quad
\textbf{Date:}\ \rule{1in}{0.4pt}
\vspace{0.5em}

\bankitem{Do Now}{%
<prompt body from registry>
}{}
\vspace{1.5in}

<if multiple Do Nows, repeat bankitem + vspace>

\end{document}
```

The `X-Y` is `3-5` for `L35_P2`. The `N` is the period number from `_P{N}_`. For APStats: `APStats 6-4 \textperiodcentered\ Period {N} \textperiodcentered\ Do Now`.

For the date-subtitle: just use the lesson title from the yaml file if it exists, else the lesson_id. Low priority polish.

5. **Only emit** if at least one Do Now item was found. Otherwise skip (report to stdout).
6. **Idempotent**: overwriting existing `tex/{lesson_id}_do_now.tex` is fine — it's generator output. But DO emit a comment header line `% GENERATED by build_do_now_tex.py on YYYY-MM-DD — do not hand-edit; regenerate instead.` at top of each file.
7. **Safety — must NOT overwrite hand-authored standalone files**: `tex/L35_P4_do_now.tex` is hand-authored. Detect hand-authored vs generated by presence of the `% GENERATED by build_do_now_tex.py` header; refuse to overwrite without a `--force` flag if header absent. Print a clear warning.
8. **pdflatex step** (`--pdf`): `pdflatex --interaction=nonstopmode --miktex-enable-installer -output-directory=tex tex/{lesson_id}_do_now.tex`. Run twice to resolve refs (matches how the Railway service does it). Log any file that fails to compile but keep going. Report success count.

### 2. Web UI — new button

**`web/index.html`** — add between Slides and Pacer buttons:
```html
<button id="btn-do-now-pdf" class="btn btn-teal">Do Now</button>
```

**`web/js/main.js`**:
- Add `const btnDoNowPdf = document.getElementById("btn-do-now-pdf");`
- In `selectLesson(id)`, HEAD-probe `pdfUrl(id, 'do_now')`; toggle `btnDoNowPdf.disabled` or `style.display` based on result. Don't block the rest of selectLesson on this — fire-and-forget. If the probe fails or 404s, hide the button.
- `btnDoNowPdf.addEventListener("click", () => openPdfView("do_now"));`
- `openPdfView` already handles any `kind` — confirm no hardcoded `kind` enum blocks `"do_now"`.
- `setPdfButtons(lesson)` — don't touch; the HEAD probe handles visibility. (Alternative: add `has_do_now_pdf` column to lessons table — but that needs another migration and seed update. **Skip the migration; use HEAD probe. Simpler.**)

Subtle: the HEAD probe should use the Supabase public object URL, which supports HEAD. No auth required for the public bucket.

### 3. Batch upload helper — `supabase/upload_pdfs.py`

The existing upload script uploaded student/teacher/slides PDFs originally. Extend the glob pattern to also upload `*_do_now.pdf` files to `lesson-pdfs/{lesson_id}_do_now.pdf`. Same upsert pattern.

If `supabase/upload_pdfs.py` doesn't exist or has diverged, **inspect first before editing** — its pattern for `kind` enumeration is the template. Read it start to finish before making changes.

## Non-goals

- Do NOT touch Railway `/build/:id` — the Railway rebuild endpoint builds `{id}_{student,teacher,slides}.pdf`, and `do_now` is a fourth flavour that we don't need to rebuild on every save. Keep Do Now generation as a local batch script, not a per-save webhook.
- Do NOT add a migration. HEAD probe handles "does the PDF exist?" at view time.
- Do NOT create a separate Supabase Storage bucket. Re-use `lesson-pdfs`.
- Do NOT generate Do Nows for lessons with NO Do Now bankitem (e.g. if a lesson ever has pure prose Do Now on the teacher board).

## Watch for these failure modes

- **MiKTeX sandbox trap**: if pdflatex emits into `tex/.miktex-sandbox/`, the build silently "succeeds" but leaves PDFs in an unexpected location. Use `-output-directory=tex` explicitly.
- **Multiple Do Nows from L63-L65**: the seed_lesson_phases output shows `do_now=3` for these. Make sure the generator picks up all three, not just the first.
- **APStats lesson id format**: `APStats_6-4_P1` — the header should read "APStats 6-4 · Period 1 · Do Now", not "Lesson 6-4".
- **Registry prompts can contain LaTeX macros** — `\(` `\)` `\frac` etc. Pass them through verbatim, don't escape.
- **Do Nows where the "body" in the teacher tex is richer than what registry has** (e.g. has extra teacher-only instructions mixed in). Trust the bank id → registry prompt; don't try to re-extract from the teacher tex body.
