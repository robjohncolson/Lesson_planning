## Objectives

- **Math Objective:** Rewrite radical/rational-exponent equations to isolate a specified variable; evaluate such rewritten formulas at given values to produce tables and graphs.
- **Language Objective:** Explain in writing which variable is being isolated and why, using a formula’s context (volume, BSA, speed).
- **Essential Understanding:** Solving a formula for a new variable is the SAME algebra as solving a radical equation — isolate the radical/rational-exponent term, raise to the reciprocal power, clean up. Works for both pure-algebra and real-world cases.

## Framework Header (Topic Goals / Essential Q / Materials)

- **Topic Goals:** Rewrite formulas to isolate a specified variable (the Topic 5 assessment’s core skill); evaluate rewritten formulas at given V/x values.
- **Essential Question:** How do we extract ANY variable from a radical/rational-exponent formula, and why does the same procedure work for both algebra and real-world contexts?
- **Materials:** Student packet, pencil, calculator for table evaluation. Practice #44 is the direct assessment rehearsal — treat it like the real test.

> **CALLOUT** — 📘  ISOLATE-A-VARIABLE RULES  _(color: #D9EAD3)_
> 
> 1. Identify which variable to isolate (look at the final answer form).
> 2. Strip away outer operations LAST-IN, FIRST-OUT (addition/subtraction last → multiplication/division → exponent/radical first to remove).

> **CALLOUT** — 📘  TABLE-EVALUATION RULES  _(color: #FFF2CC)_

> 2. Simplify rational exponents step-by-step (use calculator for irrational outputs).

> 4. The table is a point-cloud of the formula’s graph — plot the points to see the shape.

> **CALLOUT** — 📊  CONCEPT SUMMARY (your reference for Topic 5 assessment)  _(color: #DEEBF7)_
> 
> ISOLATING A VARIABLE FROM A RADICAL/RATIONAL-EXPONENT FORMULA:
>   — Identify the variable to isolate and the form of the final answer.
>   — Undo outer operations first (add/sub), then multiply/divide, then remove the exponent/radical.
>   — To undo x^(m/n): raise both sides to the power (n/m).
>   — Simplify: distribute, combine like terms, solve for the target variable.
> 
> COMPLETING A TABLE FROM A REWRITTEN FORMULA:
>   — Use your rewritten formula (e.g., x = ∛(4V) / 2) as the rule for each row.
>   — Substitute each V-value. Use a calculator for irrational outputs. Round as directed.
>   — Check: does the table’s pattern match the shape you expect (growth/decay/root curve)?
>   — Assessment Item 2 expects THIS process — from the rewritten formula to the table.
