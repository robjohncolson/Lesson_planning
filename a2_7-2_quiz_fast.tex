\noindent{\LARGE\textbf{7-2 Lesson Quiz, short form: answer key}}

\vspace{4pt}\noindent\rule{\textwidth}{0.6pt}

{\raggedright
\begin{enumerate}
\item[\textbf{1.}] \textbf{$\sin\frac{2\pi}{3}=\frac{\sqrt3}{2}$, \ $\cos\frac{2\pi}{3}=-\frac12$.} Quadrant II, reference angle $\pi-\frac{2\pi}{3}=\frac\pi3$; terminal point $\left(-\frac12,\frac{\sqrt3}{2}\right)$. Distractors: $\frac12$ and $-\frac{\sqrt3}{2}$ come from using the wrong leg (reference angle $\frac\pi6$ instead of $\frac\pi3$, the $\frac{5\pi}{6}$ point); $\sqrt3$ is $|\tan\frac{2\pi}{3}|$. Savvas quiz item 1, DOK 1, Skills Review and Practice F84. Taught by Example 4C (the same angle), so this item is a recall check of the packet. \textbf{10 points:} 5 per correct box.
\item[\textbf{2.}] \textbf{B, $\sin\theta=-\frac5{13}$.} $\sin^2\theta+\left(\frac{12}{13}\right)^2=1$, so $\sin^2\theta=1-\frac{144}{169}=\frac{25}{169}$ and $\sin\theta=\pm\frac5{13}$; in Quadrant IV the $y$-coordinate is negative, so $\sin\theta=-\frac5{13}$. Distractors: C has the wrong sign; A and D reuse 12 (the cosine's numerator) instead of solving the identity. Savvas quiz item 2, DOK 1, F84 and F92. Taught by Example 6B (the Pythagorean Identity, then the quadrant picks the sign); Try It 6a is the Quadrant IV parallel. \textbf{10 points:} B 10; C (right size, wrong sign) 5 when the work shows $\sin^2\theta=\frac{25}{169}$; 0 otherwise.
\item[\textbf{4.}] \textbf{A, C, E.} $225^\circ$ is in Quadrant III with reference angle $45^\circ$; terminal point $\left(-\frac{\sqrt2}{2},-\frac{\sqrt2}{2}\right)$, the same point as Example 4A ($\frac{5\pi}{4}=225^\circ$). \mbox{$\csc225^\circ=\frac{1}{-\sqrt2/2}=-\frac{2}{\sqrt2}=-\sqrt2$}; $\sec225^\circ=-\sqrt2$; $\cot225^\circ=\frac{x}{y}=1$. B, D and F are false (F has the wrong sign). Savvas quiz item 4, DOK 1, F84. Taught by Example 4A's terminal point and the packet's reciprocal box (Example 5, cut, holds the reciprocal definitions); the packet Practice ($135^\circ$, TE Practice 14 and Do You Know How 11) is the parallel. \textbf{Bonus 5:} A, C and E and no other box; 3 for two of the three and no wrong box; 0 otherwise.
\end{enumerate}
}
